# 云朵启动器 v1.1.6

一个用于个人 Root 设备的玉桂狗主题启动器。首页只有启动与真实运行状态，设置页负责保存卡密。

## 使用方式

1. 安装 APK 后，在 Root 管理器中授予「云朵启动器」Root 权限。
2. 将本项目的新版启动脚本放到 `/data/adb/嗯嗯启动器.sh`，并赋予执行权限：

   ```sh
   chmod 700 /data/adb/嗯嗯启动器.sh
   ```

3. 将需要启动的 `.so` 放在 `/data/adb` 的直接目录中。可以有多个文件，例如：

   ```text
   /data/adb/嗯嗯启动器.sh
   /data/adb/lib20260820_080943.so
   /data/adb/lib备用.so
   ```

4. 在「设置」页填写并保存卡密，点击「启动 SO」区域的刷新图标；从列表中选择要启动的文件。
5. 回到首页点「一键启动」。启动前会重新读取该目录，确保选择的文件仍存在。

应用实际执行的是：

```sh
su -c "/system/bin/sh '/data/adb/嗯嗯启动器.sh' -k '<已保存卡密>' -s '<选中的文件名>'"
```

新版脚本会确认所选文件仍在 `/data/adb` 中、设置执行权限，并以原有参数启动：

```sh
"$so_file" -k "$card_key" --record-mirror
```

## 运行状态

启动页会显示唯一的一条动态状态。点击状态卡可查看本次的标准输出、错误输出和退出码：

- `启动成功`：启动脚本以退出码 `0` 返回。
- `启动失败`：脚本返回非零退出码，或 Root 不可用。
- `启动超时`：五分钟内未返回。

如果原生程序自行转入后台，退出码只能说明脚本已成功交接；它无法证明后台进程之后一直存活。

## 安全与兼容性

- 卡密通过 Android Keystore 支持的加密偏好设置保存，只保存在本机。
- 输出记录会遮盖本次卡密。
- 只读取 `/data/adb` 的直接 `.so` 文件；不递归扫描子目录。
- `.so` 不需要预先拥有执行权限，脚本会在启动前执行 `chmod 700`。
- 目标 `.so` 是 ARM64 Android 可执行文件，因此设备需为 `arm64-v8a`。
- 最低 Android 版本为 8.0（API 26）。
- 当前交付的是个人使用的 debug 签名 APK；首次安装时 Android 可能显示普通的未知来源安装提示。

> v1.1.6 使用相同签名构建时可覆盖当前 v1.1.4 包，已保存的卡密会保留。若 Android 提示签名不一致，则需先卸载旧包；卸载会清除应用内保存的卡密。

## 从源码构建

使用 Android Studio 打开此目录，或在已配置 Android SDK 的环境中执行：

```sh
./gradlew assembleDebug
```

脚本路径位于 `app/build.gradle.kts` 的 `LAUNCHER_SCRIPT_PATH`，如需要可改为你自己的固定路径。
